QUESTION BANK - PLAIN HTML VERSION

This project uses only HTML.

No CSS file
No JavaScript
No Bootstrap
No external styling framework

Open index.html in a browser.

Project flow:
Home -> Registration/Login -> Course Structure -> Subject Question Paper -> Group Blog

The home page uses HTML frameset/frame because the assignment specifically asks for frame division.

Registration uses HTML form validation through required, email, date, file and other input types.

For the GitHub requirement:
1. Create a GitHub repository.
2. Open this project folder in terminal.
3. Run:
   git init
   git add .
   git commit -m "Question Bank project"
   git branch -M main
   git remote add origin YOUR_GITHUB_REPOSITORY_URL
   git push -u origin main

To use the optional video section, place an opinion.mp4 file in the same folder as blog.html.
