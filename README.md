# Question Bank

A basic B.Tech Question Bank website created using HTML.

## How to Open the Website

1. Open the repository.
2. Download/clone the repository to your computer.
3. Open the project folder.
4. Open **`index.html`** in a web browser.

> **Start the website from `index.html`.**

## Website Navigation

After opening `index.html`, use the menu on the left side to navigate through the website.

### Home
**`welcome.html`**

Provides an introduction to the Question Bank and links to the main sections.

### Student Registration
**`registration.html`**

Contains the student registration form.

### Student Login
**`login.html`**

Contains a sample student login form.

### Course Structure
**`courses.html`**

Displays the semester-wise course structure.

From this page, the available subjects can be selected to open their question papers.

### Student Blog
**`blog.html`**

Contains student photographs, comments, and opinions about the question papers.

## Question Papers

The available question papers can also be opened directly:

- **Introduction to Computing** → `introToC.html`
- **Database Management Systems** → `dbms.html`
- **Data Structures** → `DataStructures.html`
- **Computer Networking** → `computerNetworking.html`
